# Происхождение эталона ET-51

Источник: приложенный `reference-2-3.png`, 935 × 4096 px.
SHA-256: `01c01dd642d4bcd3d3e18e64e1b28efd7248f3e6405780ddd37b201264232321`.
Снимок приложения при подготовке эталонов не используется.

Исходная высота фрейма — 5611.3798828125, а не округлённые 5612 px.
Координаты секции относительно фрейма: y=2300.8798828125, размер 1280 × 833.
Воспроизведение `capabilities-reference-chromium-linux.png` из корня репозитория
(Python 3, Pillow 13):

```python
from PIL import Image

source = Image.open('.dmtools/input/ET-51/reference-2-3.png')
scale = 4096 / 5611.3798828125
source.resize(
    (1280, 833), Image.Resampling.LANCZOS,
    box=(0, 2300.8798828125 * scale, 1280 * scale,
         (2300.8798828125 + 833) * scale),
).save('e2e/ET-51.spec.ts-snapshots/capabilities-reference-chromium-linux.png')
```

При сравнении с вложением тест симметрично применяет Canvas `blur(1px)`
к эталону и снимку 1280 × 833. Это подавляет различия растеризации контуров:
вложение уже уменьшено до 935 px, его увеличение не восстанавливает исходные
контуры шрифтов. Допуск остаётся 1% при threshold=0.2; маски не используются.
`capabilities-reference-normalized-chromium-linux.png` получен только из
независимого эталона; тест проверяет его точное воспроизведение перед сравнением
с приложением. Дополнительная проверка `capabilities-figma-source` сохранена
без фильтра и с прежним допуском, чтобы контролировать мелкие детали.

В эталоне памяти указано 38 слов; приложение сохраняет 30 согласно задаче.
